Case study · 2025

Prixite Website

A technology company website, pixel-perfect across desktop, tablet and mobile.

View live site →
RoleVisual design
Timeline2025
PlatformResponsive website
ClientPrixite (in-house)

Overview

The product

I received HD wireframes as a PDF and designed the full Prixite website in Figma and, with the team, created several new pages from scratch.

My role

  • Full visual design in Figma from HD wireframes
  • New pages designed in collaboration with the team
  • Tablet and mobile versions of every page
  • Visual QA of the HTML build against Figma

One design system, every page

A consistent icon family, uniform heading and paragraph styles, and the same spacing everywhere, so the whole site reads as one system.

New pages, same language

Service detail, work and blog pages extend the system without breaking it.

Work & case pages

Responsive & visual QA

I designed tablet and mobile versions so front-end developers could follow the design accurately, then ran visual QA until the live build matched Figma pixel for pixel.

Outcome. A clean, consistent site that launched exactly as designed.
