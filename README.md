# Khurram Shehzad — Portfolio

Static site, no build step: `index.html`, one HTML page per case study, `assets/`, and `vercel.json` (clean URLs, e.g. /uptime-dashboard).

## Deploy free on Vercel
1. Create a GitHub repo (e.g. `portfolio`) and upload everything in this folder.
2. vercel.com → Sign up with GitHub → Add New → Project → import the repo.
3. Framework preset: **Other**. Leave build settings empty. Click **Deploy**.
4. Project → Settings → Domains: rename to `khurram-shehzad.vercel.app` (if free).

## Contact form (one-time step)
The "Let's talk" form sends messages through FormSubmit (formsubmit.co) to designbykhurram@gmail.com.
After the site is live, send yourself one test message — FormSubmit will email you an activation link. Click it once; after that every message arrives in your Gmail.
